## Integration Blueprint for QuantConnect/Lean.DataSource.Zerodha into eqats\n\n### Overview\nThe Lean.DataSource.Zerodha repository provides a C# data source plugin for the QuantConnect Lean engine, enabling ingestion of historical and live market data from Zerodha (Indian brokerage).\n\n### Data Engine Integration\n- **Historical Data Loader**: Use the Zerodha historical data downloader to populate eqats’ data lake with equities, futures, and options from NSE/BSE.\n- **Live Feed Adapter**: Wrap the Zerodha live tick subscriber as an eqats market‑data adapter, publishing ticks to eqats’ internal message bus.\n- **Symbol Mapping**: Leverage the existing symbol‑resolution logic to map Zerodha instrument tokens to eqats’ canonical symbols.\n- **Caching Layer**: Reuse the built‑in caching mechanism to reduce redundant network calls and improve backtest performance.\n\n### Signal & Execution Logic\nNo direct signal or execution features are present in this repository; eqats would continue to use its existing strategy and order‑execution modules.\n\n### Risk Engineering\nNo risk‑management components are included; risk limits, position sizing, and monitoring remain the responsibility of eqats’ risk engine.\n\n### Implementation Steps\n1. Add the Lean.DataSource.Zerodha project as a submodule or NuGet dependency.\n2. Implement an eqats‑specific `IDataSource` factory that instantiates the Zerodha plugin with eqats configuration (API keys, data paths).\n3. Register the factory in eqats’ data‑engine configuration so that historical backtests and live trading can select \"Zerodha\" as a data provider.\n4. Write unit tests using the provided sample data to verify symbol mapping and data integrity.\n5. Monitor latency and throughput; adjust caching policies as needed.\n\n### Expected Benefits\n- Access to high‑resolution Indian market data without building a custom feed.\n- Unified data‑engine interface allows seamless switching between Zerodha and other data sources.\n- Reduced development effort for data ingestion, allowing focus on strategy and risk modules.
