# Integration Blueprint for nse-bse-bhavcopy into eqats

## Overview
The `nse-bse-bhavcopy` repository provides a collection of NSE and BSE bhavcopy files (CSV format) generated by the associated downloader. These files contain end‑of‑day market data for equities and derivatives traded on the National Stock Exchange and Bombay Stock Exchange.

## Data Engine Integration
1. **Ingestion** – eqats’ data engine can be extended with a simple file‑system connector that watches the `nse-bse-bhavcopy` directory (or an S3 bucket if the repo is mirrored) for new CSV files.
2. **Parsing** – Each bhavcopy CSV follows a known layout: `SYMBOL, SERIES, OPEN, HIGH, LOW, CLOSE, LAST, PREVCLOSE, TOTTRDQTY, TOTTRDVAL, TIMESTAMP, ...`. A parser maps these fields to eqats’ canonical market‑data schema (timestamp, symbol, open, high, low, close, volume, turnover).
3. **Storage** – Parsed records are written into eqats’ time‑series store (e.g., PostgreSQL with Timescale extension or kdb+). The bhavcopy’s trade date serves as the partition key, enabling efficient daily retrieval.
4. **Metadata** – The repository also includes a README that notes the source downloader; eqats can retain this provenance information as part of its data‑lineage tracking.

## Signal & Execution Logic
The repository does not contain any signal generation, strategy code, or order‑execution components. Consequently, no direct integration is needed in this domain. If eqats wishes to derive signals from the bhavcopy (e.g., daily breakout, volume spikes), those would be implemented in eqats’ signal layer using the ingested data.

## Risk Engineering
No risk‑limit, position‑sizing, or monitoring features are present. Risk calculations (e.g., VaR, exposure limits) would continue to be performed within eqats’ risk engine using the market data supplied by this feed.

## Operational Considerations
- **Update Frequency** – Bhavcopy files are released after market close; the ingestion job should run nightly.
- **Data Validation** – Implement checksum or row‑count checks to detect corrupted files before persisting.
- **Scalability** – Since the volume is modest (a few MB per day), a simple file‑based loader suffices; for higher frequency intraday data, a different source would be required.

## Summary
By treating `nse-bse-bhavcopy` as a daily EOD market‑data feed, eqats can enrich its historical database with Indian equity and derivative prices, enabling more comprehensive backtesting, strategy development, and risk analysis for India‑focused portfolios.
