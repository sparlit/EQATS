# Integration Blueprint for eod2 into eqats\n\n## Overview\n\nThe eod2 repository provides a robust pipeline for downloading, storing, and adjusting NSE end‑of‑day data, along with charting and market‑breadth tools. These capabilities map naturally onto the **Data Engines** domain of eqats, while the charting and indicator features belong to **Signal & Execution Logic**, and the PE‑alert mechanism serves as a simple **Risk Engineering** monitor.\n\n## Data Engines Integration\n\n- **Ingestion**: Replace eqats’ current data‑fetcher with eod2’s download script to pull daily OHLCV and delivery data for all NSE stocks and indices. The script already handles NSE holidays, ensuring a clean trading‑day calendar.\n- **Storage & Adjustments**: Leverage eod2’s CSV layout (src/eod2_data/daily) and its split/bonus adjustment logic to maintain a survivorship‑bias‑free history. eqats can ingest these CSVs directly or map them into its internal time‑series database.\n- **ISIN Mapping**: Use eod2’s ISIN tracking to keep symbol continuity across corporate actions, feeding eqats’ instrument‑master service.\n- **Market Breadth Sync**: Schedule eod2’s market_breadth_sync.py as a daily job to compute breadth indicators (Advance‑Decline Line, % above MA, McClellan Ratio‑Adjusted Oscillator, 52‑week highs) and store them as additional time‑series feeds for eqats’ signal layer.\n- **Delivery Data**: Expose dget.py outputs as a delivery‑feed that eqats can use for liquidity‑based signals.\n\n## Signal & Execution Logic Integration\n\n- **Charting Library**: Wrap eod2’s chart.py (which uses matplotlib) as a reusable charting service within eqats, enabling interactive visualisation of strategies, equity curves, and regime plots.\n- **Technical Indicators**: Import eod2’s built‑in SMA, EMA, volume, relative‑strength, and support/resistance detectors into eqats’ indicator library.\n- **Market Breadth Indicators**: Directly reuse the four breadth indicators as pre‑computed features for regime detection or as inputs to strategy logic.\n- **AI‑Powered Plugin Generation**: Adapt eod2’s wiki‑described AI indicator generator to allow eqats users to define custom indicators via natural language, expanding the signal‑creation toolbox.\n- **Delivery‑Based Signals**: Use dget.py’s delivery‑analysis output to generate signals based on delivery‑to‑traded‑volume ratios or delivery‑trend shifts.\n\n## Risk Engineering Integration\n\n- **PE‑Alert Monitor**: Implement a lightweight risk‑watchdog that runs eod2’s NIFTY PE check (alerts when PE < 20 or > 25) and emits a risk event or adjusts position‑size limits in eqats’ risk engine.\n- **Error Handling & Data Integrity**: Adopt eod2’s try/except patterns and validation checks to safeguard eqats’ data pipelines against corrupt downloads or missing files.\n- **Holiday Calendar**: Re‑use eod2’s holiday lookup to ensure eqats never submits orders on non‑trading days and to align backtesting windows with actual market sessions.\n\n## Implementation Steps\n\n1. **Vendor the eod2 code** (or install via pip if published) and expose its core functions as a Python module.\n2. **Create an adapter** that translates eod2’s CSV outputs into eqats’ canonical data‑model (e.g., Pandas DataFrame with standard column names).\n3. **Schedule the download & sync jobs** using eqats’ existing job‑runner (cron, Airflow, or Prefect) to run after market close.\n4. **Register the breadth and delivery series** as external feeds in eqats’ feature store.\n5. **Plug the charting functions** into eqats’ notebook‑or‑dashboard layer for strategy visualisation.\n6. **Add the PE‑alert as a risk rule** in eqats’ risk‑engine configuration, mapping the alert to a max‑leverage or exposure limit adjustment.\n7. **Run integration tests** comparing eod2‑derived data with eqats’ existing data sources to ensure parity.\n\n## Expected Benefits\n\n- **Data quality**: Automatic corporate‑action correction and holiday awareness reduce look‑ahead bias and survivorship bias.\n- **Feature richness**: Ready‑made breadth and delivery indicators accelerate strategy research.\n- **Visualisation**: Interactive charting shortens the feedback loop between idea generation and execution.\n- **Risk monitoring**: Simple PE‑based alerts provide an early‑warning system for market‑wide valuation extremes.\n\n## Conclusion\n\nBy incorporating eod2’s data‑engine, signal‑generation, and risk‑monitoring components, eqats gains a battle‑tested, NSE‑focused data pipeline and a suite of analytical tools that can be directly leveraged for systematic trading strategies.
