# hypersdk Integration Blueprint for eqats\n\n## Overview\nhypersdk is a Rust SDK for Hyperliquid offering real‑time market data via WebSocket, order placement with EIP‑712 signing, and HyperEVM contract interactions. It provides the building blocks for eqats’ data engines, signal/execution logic, and risk engineering.\n\n## Data Engines\n- Subscribe to trades, L2 books, user events, and active asset data through `hypercore::mainnet_ws()`.\n- Query perpetual and spot markets via `client.perps()` and `client.spot()` for instrument metadata.\n- Use HIP‑3 to fetch perpetual data from multiple DEXes.\n- Monitor asset transfers between perps, spot, and EVM layers.\n\n## Signal & Execution Logic\n- Place, cancel, modify orders with `client.place(signer, order, nonce, ...)` (returns `impl Future` for easy `tokio::spawn`).\n- Leverage `rust_decimal` for precise price/size calculations and tick‑rounding.\n- All HyperCore actions are type‑safe EIP‑712 signed via `alloy`.\n- Interact with HyperEVM contracts (Morpho, Uniswap) directly for DeFi strategies.\n- The `hypecli` CLI enables quick manual testing.\n\n## Risk Engineering\n- Derive max leverage from market metadata to enforce position‑size limits.\n- Use the `reduce_only` flag on orders to automatically cut exposure.\n- Stream user events (`UserEvents`, `ActiveAssetData`) for real‑time margin and liquidation monitoring.\n- Track cross‑layer transfers to maintain accurate collateral calculations.\n\n## Integration Steps\n1. Add `hypersdk = \"0.2\"` (plus `tokio`, `anyhow`) to eqats’ Cargo.toml.\n2. Create a HyperCore client (`hypercore::mainnet()`) and a WS client (`hypercore::mainnet_ws()`).\n3. Run background WS tasks to feed eqats’ market‑data cache and risk monitor.\n4. Implement an execution adapter that maps eqats signals to `OrderRequest` and calls `client.place`.\n5. Apply `rust_decimal` math and hypersdk’s tick‑rounding before sending orders.\n6. For DeFi strategies, use the `alloy` bindings exposed by hypersdk to call HyperEVM contracts.\n7. Use `hypecli` for ad‑hoc overrides or debugging.\n\n## Outcome\nWith hypersdk, eqats obtains a low‑latency, type‑safe gateway to Hyperliquid’s spot/perp markets and HyperEVM DeFi, cleanly separating data ingestion, order execution, and risk‑relevant feeds.
