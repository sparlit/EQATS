# Integration Blueprint\n\n## Overview\nIntegrate the NSE equity research report generator's valuation engine into eqats as a signal generation module.\n\n## Components\n- **Data Engine**: Reuse yfinance-based data fetching with disk cache; expose via Rust struct NseDataFetcher.\n- **Signal & Execution Logic**: Implement two-stage FCFF DCF, model blend, confidence score, and rating logic in Rust, callable via PyO3 from Python or as native Rust.\n- **Risk Engineering**: Expose forensic screens as Rust functions for risk filtering.\n\n## Data Flow\n1. eqats provides ticker and optional parameters.\n2. Rust module fetches financials (cached) via Python's yfinance wrapper.\n3. Valuation engine computes intrinsic value, target price, confidence score.\n4. Signal module outputs a structured signal (intrinsic value, target, confidence, rating).\n5. Risk module can flag based on forensic screens.\n\n## Implementation Details\n- Use PyO3 to create a Python extension module eqats_nse that exposes valuation(ticker: str) -> dict.\n- Rust core can call this via pyo3::Python::with_gil.\n- Configuration via config.yaml overridden by env vars.\n- Unit tests compare against known-answer cases from the original test suite.\n\n## Build & Deploy\n- Add pyo3 dependency to Cargo.toml.\n- Build with maturin develop or cargo pyo3 build.\n- Ensure system libraries (libpango, libcairo) for PDF generation if needed (optional).\n\n## Testing\n- Run pytest on Python side to ensure parity.\n- Rust unit tests using assert_eq! with golden outputs.\n
